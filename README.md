# GoblinNestDebug
A basic mod that adds a debug/cheat menu for basic use or debugging 

Fully compatible with Goblin Nest v1.33 versions of the Moan Mod and Frieren mod.

Many features will be added as requested.

At it's current state this mod is functional but not 100 finished.

Two of the modified game scripts for v1.0 has been included for anyone interested in the UI section. These two files are where the majority of debug code is held.

Full source code can be viewed through UMT by copying the modified data.win file after G3M has patched it.
